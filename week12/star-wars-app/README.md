 Star Wars App 🚀
 
Kullanıcıların **Star Wars evrenindeki yıldız gemilerini listeleyip detaylarını inceleyebileceği** bir uygulamadır.


## 📌 Özellikler

- ✅ Yıldız gemilerini API üzerinden listeleme
- ✅ Arama kutusu ile **ad veya modele göre** arama yapma
- ✅ Her bir gemi için:
  - Ad
  - Model
  - Maksimum hız
- ✅ Detay sayfasında:
  - Yolcu sayısı
  - Atmosferdeki maksimum hız
  - Üretici
  - Mürettebat
  - Kargo kapasitesi
- ✅ “Daha Fazla Yükle” butonuyla API üzerinden diğer sayfalardaki gemileri getirme
- ✅ Detay sayfasından ana sayfaya geri dönebilme
- ✅ Bootstrap ile responsive ve modern tasarım

---

## 🛠️ Kullanılan Teknolojiler

- React
- React Router DOM
- Bootstrap 5
- Fetch API
- SWAPI – [https://swapi.tech](https://swapi.tech)
